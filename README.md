Стратегия рекомендательного сервиса
Как работает: Сервис получает user_id, ищет для него кандидатов от ALS, ранжирует их CatBoost моделью с фичами (популярность, категории, активность) и возвращает топ-K. Есть стратегия Fallback: если для пользователя нет ALS-кандидатов (cold-start), возвращаем Top Popular товары.


Интерпретация метрик
- Recall@10 = 1.27%

Из всех товаров, которые пользователь реально купит, модель угадывает ~1.3% в первых 10 рекомендациях. Это то, что пользователь видит на первой странице.

- Recall@100 = 3.21% — расширяя до 100 рекомендаций, угадываем ~3.2% покупок.

Немного, но для e-commerce с миллионами товаров и непредсказуемым поведением это нормальный результат.


- Precision низкий (0.08-0.29%) — из 100 рекомендаций только 1-3 реально купят. Это ожидаемо: рекомендуем много (100), покупают мало (1-5 товаров).


Вывод: Модель работает, персонализация ALS  улучшает baseline (просто топ-продукты) 11-19%, поднимая релевантные товары выше в списке.
